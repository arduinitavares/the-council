# Direct CLI Dispatch Over MCP/UTCP and Pure Telemetry Observer for Live Visualization

We evaluated MCP (`@modelcontextprotocol/sdk`), UTCP (`@utcp/sdk` + `@utcp/cli`), and direct `node:child_process.execFile` at both the outbound (`CouncilEngine` → `HarnessAdapter`) and inbound (`Caller` → `bin/council`) seams. Because `agy`, `codex`, and `cursor-agent` are local CLIs rather than MCP servers, both MCP and UTCP fail the deletion test on the outbound seam—introducing JSON-RPC wrapper servers or shell-interpolated `${prompt}` templates (`CliCallTemplate`) and external npm dependencies without making `HarnessAdapter` (`executeSeat`, `executeJudge`) any deeper. We therefore use `execFile` directly behind `HarnessAdapter`, expose the inbound seam as `bin/council` + the `/ask-council` skill, and stream live runs to `src/visualizer/live-run-latest.js` through a pure `VisualizerLiveWatcher` subscriber on `CouncilTelemetryEmitter` so `CouncilEngine` remains decoupled from filesystem I/O.
