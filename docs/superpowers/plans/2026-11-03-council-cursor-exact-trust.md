# Council Cursor exact trust implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prevent a colliding Cursor marker key from verifying another packet workspace, while retaining separately evidenced native direct/eligible-ancestor admission.

**Architecture:** Put bounded marker acquisition and exact comparison in one synchronous Cursor trust module. Keep native admission separate from Council identity, then bind the acquired evidence through a versioned private witness and revalidate it at reuse, spawn and input. The first increment fixes the overstatement and tests positive acquisition offline; production trust remains unsupported until the launch contract and local namespace facts are established.

**Tech Stack:** TypeScript ESM, Node filesystem descriptors, SHA-256, existing `decodeStrictJson` and Zod contracts; bounded direct-source fixtures on Node `22.23.4`.
