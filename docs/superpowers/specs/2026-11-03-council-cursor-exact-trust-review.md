| F1. Identify the actual launched build and keep positive fixtures offline. | Accepted. | F2. Preserve the final synchronous input guard. | Accepted with a qualification. [load.ts](../../../src/config/load.ts#L53) is an async example of bounded descriptor reads. The current wrapper has a no-await section after parsing and immediately before call reservation at [provider-session.ts](../../../src/pilot/provider-session.ts#L362). Plan a final synchronous, bounded witness check followed by the current cancellation, deadline and error guard before reservation and write. Any awaited preliminary work goes before the final guard. Even synchronous work can consume the remaining deadline. The check still cannot make Cursor's later independent trust lookup atomic. |
| F3. Give every failure an explicit state and a safe reason. | Accepted with a distinction. [wrapper-contract.ts](../../../src/pilot/wrapper-contract.ts#L143) prioritizes `denied`, while [provider-controls.ts](../../../src/pilot/provider-controls.ts#L254) currently adds a separate metadata fact and then reports missing trust. Record an evidenced refusal as `denied` for the affected predicate, incomplete evidence as `unknown`, a complete negative lookup as `missing`, and an unqualified contract as `unsupported`. Native admission can remain verified when an independently established existence predicate succeeds but reading the contents for Council identity is refused. Replace the separate metadata fallback in the new trust contract. Keep fact reason codes, audit errors and provider diagnostics distinct. Project only bounded allowlisted reasons. |

## Independent source verification and approval boundary

The coordinator matched all 21 saved byte ranges against the installed launcher and two pinned bundles, including the direct existence check, the ancestor directory-name set and both writers. Two distinct synthetic packet paths produced the same lookup key. The stored-path comparison addresses that ambiguity under the design's filesystem assumptions. No real trust marker was read and no Cursor process was started. [Static verification receipt](../../../.superpowers/sdd/2026-11-01-council-bounded-diagnostics/issue5-design-coordinator-static-check.json)

Ancestor admission requires host evidence of equivalent candidate selection. Cursor uses an exact directory-name set for ancestors, so direct filesystem probes on a case-insensitive volume can produce a false match. Also specify who establishes the owned packet directory before read-only discovery. Current discovery derives its path, while the wrapper checks bootstrap facts before it creates the directory. A missing directory must continue to block exact trust until the authorized preparation order is defined.
